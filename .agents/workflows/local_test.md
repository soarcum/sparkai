这是在 Antigravity IDE 环境下进行本地极速测试和真机 UI 截图验证的自动化工作流。

## 🎯 工作流目标
代替用户在本地完成真机的快速打包部署、APP 自动拉起、实时 UI 截图以及错误日志追踪，将原本 5 分钟的 GitHub 部署流程压缩至 10~20 秒的秒级反馈闭环。

## 📋 执行步骤

### 1. 设备无线连接检测
在运行任何打包命令前，AI 助手必须首先检测并建立与手机的 adb 无线连接：
- 检查当前连接设备：在根目录下运行 `adb devices`。
- **若未连接**：主动提示用户并询问手机“无线调试”主界面上最新显示的 `IP:PORT`（例如 `192.168.110.32:40445`）。
- **执行连接**：运行 `python test_helper.py connect <IP:PORT>`，直到 `adb devices` 能正确显示已连接设备。

### 2. 本地一键打包与无线部署
连接成功后，AI 助手直接在本地执行增量打包与真机覆盖安装：
- **运行命令**：在后台执行 `python test_helper.py deploy`。
- 该命令会全自动调用本地 Gradle 执行增量构建，生成 Debug 版本的 APK，并通过局域网无线推送到真机完成安装，最后自动在真机屏幕上拉起应用。

### 3. 真机 UI 截图验证 (核心)
应用成功在真机拉起后，AI 助手必须将真机当前的画面反馈给用户进行物理确认：
- **运行命令**：在根目录下执行 `python test_helper.py screenshot` 截取手机当前画面。
- **展示给用户**：在聊天窗口中直接通过标准的 Markdown 图片语法将该截图渲染并呈现出来：
  `![手机当前屏幕截图](file:///c:/Users/Administrator/Desktop/cool/sparkai/local_test_screen.png)`
- 邀请用户确认当前的 UI 交互与显示是否正确。

### 4. 报错诊断与实时修复
在测试过程中，如果遇到应用闪退、卡死或接口无反应：
- **抓取日志**：AI 助手必须主动运行 `python test_helper.py logcat`，获取真机最新的崩溃堆栈或 Error 日志。
- **自动修复**：分析日志并直接修改本地出错的代码，随后重新回到 **【步骤 2】** 进行极速验证，直到测试完全通过！
